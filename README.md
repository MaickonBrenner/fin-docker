# FinDocker
## 🧾 Finanças sob controle, em qualquer container.
 FinDocker é uma aplicação de gerenciamento financeiro pessoal construída com Docker, pensada para quem valoriza controle, privacidade e portabilidade. Com uma interface intuitiva e arquitetura modular, você pode acompanhar receitas, despesas, metas e relatórios, tudo rodando em containers leves e seguros.

## 🚀 Funcionalidades
- 📊 Dashboard financeiro com visão geral de receitas, despesas e saldo
- 🗂️ Categorias personalizadas para organizar seus gastos
- 📅 Planejamento mensal com metas e alertas
- 🔐 Segurança de dados com armazenamento local ou em volumes protegidos
- 🐳 Deploy via Docker em qualquer ambiente compatível
- 📈 Relatórios exportáveis em PDF ou CSV (em breve!)

## 🛠️ Tecnologias Utilizadas
- Docker – containerização e portabilidade

## 📦 Instalação
### Linux
 Em um terminal Linux, digite os seguintes comandos: <br>
 ```
 git clone https://github.com/MaickonBrenner/fin-docker.git
 cd findocker
 docker-compose up -d
 ```
### Windows
 No CMD do Windows, digite:
 ```
 git clone https://github.com/MaickonBrenner/fin-docker.git
 cd findocker
 docker-compose up -d
 ```
